# Text Preprocessing Summary

## Overview
Successfully completed text preprocessing on Indonesian news articles dataset containing 152 articles from various sources (Detik, Liputan6, Kompas, Tribun, CNN Indonesia).

## Preprocessing Steps Applied

### 1. Text Cleansing
- Removed numbers and special characters
- Converted text to lowercase
- Removed extra whitespace
- Handled missing/null values

### 2. Tokenization
- Split text into individual words using NLTK word_tokenize
- Preserved word boundaries and meaningful tokens

### 3. Stopword Filtering
- Removed common Indonesian stopwords using NLTK Indonesian stopwords
- Preserved content-bearing words for analysis

### 4. Stemming
- Applied Sastrawi stemmer to reduce words to their root forms
- Limited processing to 1000 tokens per article to optimize performance
- Handled edge cases and errors gracefully
